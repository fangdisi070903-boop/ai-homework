## 四、快速开始

```bash
cd "课程项目作业-出院随访与患者协作 业务挖掘/mvp"

python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

.venv/bin/python -m pytest -q            # 期望：7 passed
.venv/bin/python harness/run_eval.py     # 期望：29/29 通过，写入 harness/report.json
.venv/bin/uvicorn app.main:app --reload  # 交互式文档：http://127.0.0.1:8000/docs
```

演示账号：`admin_qh / admin123`（管理员）、`doctor_wang / doc123`（医生）、`nurse_zhou / nurse123`（随访护士）、`patient_li / pat123`（患者）。
