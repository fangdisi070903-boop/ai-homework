## 一、用药（遵医嘱，勿自行调整）

| 药物类别 | 注意事项 |
| --- | --- |
| 利尿剂（如呋塞米） | 按医嘱服用；记录每日尿量与体重；出现明显乏力、腿抽筋请及时联系医生 |
| ACEI/ARB/ARNI | 起身动作放缓，注意有无头晕、干咳 |
| β 受体阻滞剂 | 监测心率，静息心率低于 55 次/分请咨询医生 |
| 其他 | 按出院医嘱执行 |

> **重要**：药物的剂量、停药、换药**必须由医生决定**，出院指导单不提供剂量调整建议。如有疑问请拨打心内科门诊电话或复诊。

## 二、每日自我监测（心衰患者必须执行）

1. **每天早晨起床排尿后、早餐前，固定时间称体重**，记录在随访手册上。
2. 记录每日饮水量与尿量（可用带刻度水杯、量杯）。
3. 观察双下肢有无水肿、夜间能否平卧、活动后气促程度。

**出现以下任一情况，请当天联系医院（心内科门诊 / 随访电话），不要等到复诊日：**

- 3 天内体重增加 ≥ 2 kg；
- 平卧呼吸困难、夜间需坐起；
- 双下肢水肿明显加重；
- 尿量明显减少。

## 三、饮食与生活

| 项目 | 要求 |
| --- | --- |
| 盐 | 每日食盐 < 5 g（约一啤酒瓶盖），避免咸菜、腊肉、加工食品 |
| 水 | 每日饮水量遵医嘱（一般为 1500–2000 ml，具体以医生交代为准） |
| 体重 | 保持稳定，避免短期内明显增减 |
| 活动 | 以不引起气促为度，可散步；避免屏气用力 |
| 戒烟限酒 | 必须戒烟，避免饮酒 |
| 睡眠 | 保证 7–8 小时，打鼾严重者告知医生 |
