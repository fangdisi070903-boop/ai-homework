## 交叉核实关系

```text
D-02 制度要求（应然）
   ├─ 对照 D-03 实际记录（实然）→ 发现"未接通即标记完成"(C-02)
   ├─ 对照 D-04 统计口径        → 发现两套完成率 72.4% / 91.2%(C-04)
   └─ 对照 D-01 指导单内容      → 发现宣教与记录脱节(C-01)

D-03 与 D-04 的样本口径必须一致（同为 2025-Q3、同院同诊断），否则不能直接比较。
```

## 使用与脱敏说明

1. 4 份资料均为课程模拟件，医院与人物虚构，不含真实患者信息。
2. 患者一律以 `MRN` 标识；导出文件不含身份证号、完整手机号、住址（对应制度第 6 章与授权书 QH-DATA-2026-037）。
3. 资料只读引用，不在资料文件内修改数据；所有加工结果写入 `data/` 与 `mvp/`，便于回溯原始依据。
